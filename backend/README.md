# Backend — Python / FastAPI

REST API for the HMCTS Task Manager. Provides CRUD endpoints for managing caseworker tasks, with automatic Swagger/ReDoc documentation and Pydantic request validation.

---

## Prerequisites

- Python 3.13+
- PostgreSQL 16 (or run via Podman/Docker — see root README)

---

## Setup

```bash
cd backend
python3.13 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Edit `.env` with your database credentials:

```
DATABASE_URL=postgresql+psycopg://hmcts:hmcts@localhost:5432/tasks_db
PORT=8000
```

---

## Run database migrations

```bash
alembic upgrade head
```

---

## Start the server

```bash
uvicorn app.main:app --reload --port 8000
```

Server runs at `http://localhost:8000`

---

## API Documentation

Once running, documentation is auto-generated by FastAPI:

| URL | Description |
|---|---|
| `http://localhost:8000/docs` | Swagger UI — interactive endpoint explorer |
| `http://localhost:8000/redoc` | ReDoc — readable API reference |

---

## API Endpoints

| Method | Path | Description | Status |
|---|---|---|---|
| `POST` | `/tasks` | Create a task | 201 |
| `GET` | `/tasks` | Retrieve all tasks | 200 |
| `GET` | `/tasks/{id}` | Retrieve task by ID | 200 / 404 |
| `PATCH` | `/tasks/{id}` | Update task status | 200 / 404 |
| `DELETE` | `/tasks/{id}` | Delete a task | 204 / 404 |
| `GET` | `/health` | Health check | 200 |

## Project structure

```
app/
  main.py          # FastAPI app entry point
  config.py        # Environment config via pydantic-settings
  database.py      # SQLAlchemy engine, session, get_db dependency
  models.py        # SQLAlchemy Task model
  schemas.py       # Pydantic request/response schemas
  exceptions.py    # Global SQLAlchemy error handler
  routers/
    tasks.py       # CRUD route handlers
alembic/
  env.py           # Alembic migration environment
  versions/        # Migration scripts
tests/
  unit/            # Schema validation tests
  integration/     # Endpoint tests via TestClient
requirements.txt
pytest.ini
.env.example
```
