# Frontend — TypeScript / Express

Server-rendered frontend for the HMCTS Task Manager.

## Prerequisites

- Node.js 20+

## Setup

```bash
cd frontend
npm install
cp .env.example .env
```

## Run

```bash
npm run dev
```

Runs at http://localhost:3100

## Build

```bash
npm run build
npm start
```

## Test

```bash
npm test
```
